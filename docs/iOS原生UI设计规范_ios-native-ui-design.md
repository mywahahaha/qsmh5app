# iOS原生UI设计规范

- 版本：v1.0，调整 iOS 更新按钮留白与标题字号；日期：2026-11-05。
- 对应：[iOS开发总体方案](iOS开发总体方案_ios-development-proposal.md)。
- 视觉目标：与当前 Android 的品牌、颜色、结构和交互保持一致；系统界面及 SDK 强制限制明确作为平台适配。
- 交付形式：本文定义数值和状态，[界面预览](iOS原生界面预览_ios-native-ui-preview.html)辅助评审。预览不是真实 iOS SDK 或真机截图。
- 已确认本次不开发分发模式及充值专项；更新界面使用通用“打开更新入口”语义，隐私撤回纳入需求。原生侧加载 H5 游戏地址，H5 充值相关跳转遵守统一白名单与导航拦截规则。

## 1. 设计依据和优先级

1. 用户要求两端原生 UI 一致。
2. 阿里云一键登录业务、素材和最新头部高度，以[一键登录独立需求](阿里云一键登录独立需求_aliyun-onekey-login.md)为业务参考。
3. 更新弹窗视觉参考当前 UpdateDialog.kt、随包 update_header.png 及已保存 Android 截图。
4. iOS 使用 pt，不将 Android 截图物理像素直接当作 pt。官方 SDK 控件最小尺寸和系统安全区域优先满足。
5. 本文明确的差异需要在开工前确认；不因 Android 代码存在某个值，就视为它满足 iOS 的可读性与 SDK 限制。

更新弹窗尺寸按服务端字段直接计算，iOS 不再套用 Android 的 0.7 缩放。

## 5. 坐标、方向与安全区域

定义 hostBounds 为当前 UIWindowScene 下实际容器 bounds，不使用 UIScreen.main.bounds 推算多窗口或横竖方向。背景可以铺满 hostBounds；可点击弹窗位于 safeArea 内再内缩 12pt 的可用矩形 R。

原生授权弹窗百分比以 R.width、R.height 分别计算。数值型页面布局单位按 pt；普通 H5 窗口沿用宿主 safeArea 布局。**H5 的宽度、高度同时为 `100%` 时，整个 WebView 直接覆盖 hostBounds，忽略偏移，不再由宿主预留四边安全间距。** 页面背景允许延伸到屏幕边缘，H5 自行用 `env(safe-area-inset-*)` 避让可点击内容；原生授权弹窗使用安全区域。悬浮球水平使用整个窗口以满足 `right: 0` 贴屏幕边缘，纵向仍限制在安全区域内。

viewSafeAreaInsetsDidChange、viewDidLayoutSubviews 或有效方向/窗口变化时重新计算布局；不把首次计算的固定像素永久保存。H5 需要全屏内容时通过 safe-area-inset-* 适配操作区域；必要时约定宿主 inset，不能同时由宿主和 H5 重复加安全边距。

2026-11-03 补充：业务 H5 容器禁用原生页面拖动、回弹、缩放、滚动条及前后滑动导航，自动 content inset 为零，补充 `viewport-fit=cover`；隐藏网页滚动条并阻止浏览器原生 HTML 拖拽，H5 的按钮、输入、触摸事件保持可用。不强改 H5 业务样式中的 margin/padding；需要长内容时由 H5 在内部滚动区实现阅读。SDK 运营商/业务协议详情保留 SDK 原生阅读和返回能力。

建议例：横屏可用 R=800×340pt，一键登录 60%×75% 得到 480×255pt；iOS 与 Android 全屏比例相同，但可点击区域的绝对值因安全区域不同而不同。

## 6. UI03：一键登录授权弹窗

### 6.1 面板和头部

| 项目 | 设计值 |
| --- | --- |
| 宽高 | R.width × dialog_width_percent / 100；R.height × dialog_height_percent / 100 |
| 默认配置 | 宽 60%、高 75%；取服务端 iOS 配置，不在客户端另放大 |
| 圆角 | 14pt |
| 头部总高 | 53.7pt；构建 8 按真机反馈增加 10pt |
| 红色主体参考高 | 随头部弧形路径计算，不使用旧 34.5pt 固定高度定位控件 |
| Logo 可见框 | 102×34pt；距左 10pt；按整个标题区域垂直居中 |
| 关闭图形 | 白色细线 ×，右侧视觉边距约 10pt |
| 关闭命中 | 至少 44×44pt；图形及点击区域均按整个标题区域垂直居中，不压住协议或号码 |
| 标题 | 忽略 ui.title，不显示“手机快捷登录”等文字 |
| 遮罩点击 | 不关闭；只有关闭、其他方式或系统允许的返回触发取消 |

头部底边：从右下角到左下角，以 (W/2, H×0.62) 为二次贝塞尔控制点形成中间上收的弧线；顶部圆角与卡片一致。iOS 不复制 Android SDK 的 50dp 内容偏移，坐标全部基于 iOS SDK 实际 contentView。

构建 7 实施：通过 TXCustomModel 的弹窗、frame block、customViewBlock 和 expandAuthPageCheckedScope 公开配置接入品牌头、真实业务协议、默认未勾选、说明点击切换及 SDK 协议校验；横竖方向仍与实际游戏包一致。正常与紧凑布局按完整协议测量，放不下时回退 H5。实现及验证边界见[授权 UI 与全屏修复记录](iOS授权品牌UI与全屏容器修复_ios-auth-ui-fullscreen.md)。

### 6.2 内容尺寸与布局

| 内容 | 设计 |
| --- | --- |
| 脱敏号码 | SDK 提供；28pt 默认，紧凑状态最低 20pt；#555555，居中 |
| 运营商说明 | SDK 提供；12pt 默认，不能替换成固定运营商 |
| 登录按钮 | 宽 82% 面板宽；高 44pt，任何状态不得低于 SDK 40pt；橙底白字、16pt、圆角 5pt |
| 其他方式 | 13pt、#666666，文字读取 other_login_text；可点区域高 44pt |
| 协议 | 12pt 起、正常换行；文字 #666666，链接蓝色，不能小于 SDK 下限 |
| 复选框 | 可见 14×14pt，默认未勾选；透明命中可扩大至 44pt |
| 内容水平边距 | max(16pt, 面板宽×9%) |
| 常规区域间距 | 号码到说明 4pt；说明到按钮 16pt；按钮到其他方式 8pt；协议到底部 16pt |

采用“头部固定、底部协议按完整文本测量，中间内容按约束排列”：

1. 协议框按真实运营商条款与最多两项业务协议测量完整高度。
2. 从 53.7pt 头部下方预留号码、说明、按钮、其他方式；测量各行实际字体高度。
3. 内容能放下时使用常规间距；紧凑时可将非触控间距压缩到 2pt、协议底距到 8pt；按钮和其他方式的 44pt 点击高度不变。
4. 按钮与可点区域不低于平台约束，协议不裁切，不用 6–10pt 字体模拟 Android 小尺寸。
5. 仍放不下则判该授权配置不可展示，展示前返回 3001 并保留/创建 H5 登录；不偷偷增大服务端比例或交付叠压界面。建议服务端对竖屏窄窗提供适合手机的独立比例，先在 S0 验证。
6. iOS 版本最终授权控件位置通过 TXCustomModel 的 contentViewFrameBlock、numberFrameBlock、loginBtnFrameBlock、privacyFrameBlock 等公开能力实现；字段与锁定包头文件逐项核对。

本设计适配正常/紧凑配置，不能保证所有 1%–100% 组合均能承载完整授权内容。业务协议前两项必须有合法名称和地址；额外协议是否合并展示须由产品确认，不能静默丢弃应展示的必需条款。

### 6.3 交互状态

| 状态 | UI 和回调 |
| --- | --- |
| 准备 SDK | 保留当前 H5；可有短暂系统加载指示，不返回唤起成功 |
| 收到已展示事件 | 授权可见；回调原 H5 code=0、data=true；JS 执行完成后关闭对应 web_login |
| 未勾选点击登录 | SDK 校验协议并提示；不取号、不兑换、不自动勾选 |
| 点击普通协议说明 | 切换选中状态；使用 SDK 支持的状态接口，同一点击不能与 SDK 默认处理重复切换 |
| 点击链接 | 只打开该协议，不改变勾选 |
| 取凭证中 | 防重复提交，使用 SDK 等待态；关闭动作可取消并失效该流程 |
| 关闭或其他方式 | 关闭 SDK 认证页，取消旧流程，展示新的 H5 登录；不再次回调已完成的唤起请求 |
| 已获凭证 | 关闭授权页、清理遮罩，进入 UI05 业务兑换等待；仍未登录成功 |
| 兑换失败 | 中文短提示，回到 H5 登录；不重新发送第一次 Bridge 回调 |
| 兑换成功 | 保存业务 Token 后打开游戏；只允许当前会话写入 |

禁止直接在真实登录按钮、号码或必需协议上叠加自制可点击视图来绕过 SDK 检查。若锁定 SDK 不支持“普通说明切换勾选”，S0 必须验证公开富文本/事件配置是否能达成；无法达成时记录为待确认的平台交互差异，不私自遍历修改 SDK 私有视图。

## 7. UI04：协议详情与 UI05：兑换等待

### 协议详情

导航栏 #C52D28，返回图形/标题白色，标题 17pt。内容为实际协议地址，白底，随 safeArea 布局。优先使用 SDK 协议页面公开配置 privacyNavColor、privacyNavTitleColor 等。

协议页面是无业务 Bridge 的低权限内容。加载失败允许重试和返回；返回恢复原授权页、原勾选状态，不重复拉起、不自动取号。系统交互式返回与点击返回等价，不等价于取消整个认证。

### 兑换等待

原生小型指示器与“登录中，请稍候…”显示在根容器，不伪造百分比。正文 14pt，最大宽 280pt；背景与游戏启动底色一致。请求连接/读取各建议 15 秒，并以总流程取消规则收敛；不能无限等待。

H5 原登录窗口已关闭时，兑换失败创建新实例；不复活旧文档。真正进入后台、logout 或宿主释放时取消/失效本轮等待，临时 inactive 不直接视为取消。进入后台时若 Token 尚未提交，下次前台显示新的 H5 登录，不自动重弹授权；若已原子提交则保留登录态，前台显示游戏。后台事件和 Token 提交串行排序，旧结果不得越过取消边界；任一路径均移除等待指示器。

## 8. UI06：在线更新弹窗

### 8.1 iOS 更新弹窗尺寸规则

~~~text
width 为纯数字：W = width dp，按 iOS 1 dp = 1 pt 使用
width 为“数字%”：W = R.width × width / 100
height 为纯数字：H = height dp，按 iOS 1 dp = 1 pt 使用
height 为“数字%”：H = R.height × height / 100
height 为 auto：H = 内容实际测量高度
最终卡片高度 = min(高度候选, 预留安全边距和关闭控件后的可用高度)
~~~

圆角为 10.5pt。头图理想高度按 W×198/530×0.8，比上一版缩短 20%；背景图可纵向拉伸。横屏可用高度不足时继续压缩头图，优先留出说明、版本时间和主按钮，不改变配置宽度。iOS 在安全区域内限制超出屏幕的尺寸；不对小宽度配置擅自扩宽或直接跳过弹窗。

例如 R 宽 800pt 时，width=320 得到 320pt，width="50%" 得到 400pt；两者均不再额外缩放。height="auto" 时由标题、说明、版本时间和按钮的实际内容决定卡片高度。

### 8.2 内容与样式

| 元素 | Android 参考算式 | iOS 落地 |
| --- | --- | --- |
| 标题 | 直接按 iOS pt | 白色粗体 24pt，整体上移约 5pt，行高为默认的 80%；长标题换行 |
| 更新说明 | 直接按 iOS pt | #FF590C，18pt，居中换行；上下各留 10pt；空则隐藏 |
| 版本/日期 | 直接按 iOS pt | #757575，13pt；显示“最新版本：x  更新时间：yyyy-mm-dd”，两项间距 30pt；服务端字段为空时显示 `--` |
| 主按钮 | 宽度随卡片，高 40pt | 绿色胶囊；白字 16pt；按钮上下各留 20pt |
| 关闭 | 33×33pt 可见圆形 | 纯黑色 #000000，白色 #FFFFFF 的 × 缩小一号并由圆心坐标绘制；点击区域 44×44pt |
| 间距 | 固定 iOS 间距 | 内容不重叠；较大字体先滚动正文 |
| 遮罩 | 45% 黑色 | 一致，点击不关闭 |
| 滚动 | 卡片内容过长 | 卡片内说明与版本区域滚动，主按钮固定在卡片底部、关闭固定在卡片外；不把主操作滚出可见范围 |

若服务端给出很小的固定尺寸，例如 width=50，弹窗仍按 50pt 显示，但文字和按钮可能无法完整呈现；运营配置应提供足够的 dp 或百分比尺寸。

### 8.3 更新状态与文案

| 状态 | 可见内容与动作 |
| --- | --- |
| 非强制提示 | 黄色头图、title、desc、版本/日期、绿色“立即更新”、下方圆形关闭 |
| 强制提示 | 同上，隐藏关闭；遮罩和返回不关闭 |
| 点击更新入口 | 按钮短暂禁重复点击，可显示“正在打开…”；无下载进度 |
| 系统接受跳转 | 系统浏览器打开受控 HTTP/HTTPS 更新页，不在业务 WebView 内处理安装 |
| 从外部入口返回 | 非强制可关闭并继续登录；正常强制仍保留提示，可再次打开更新入口 |
| 地址无效或打开失败 | 短提示“暂时无法打开更新，请稍后再试”，结束本次更新并继续登录，force=1 也放行 |
| 服务端关闭更新 | `open=0` 时不弹更新并继续登录；是否已是当前或较旧版本由服务端判断 |

本次不设计“下载中 35%”“下载完成”“立即安装”状态，也不绑定 App Store、TestFlight 或企业安装页样式。实际安装由外部分发流程处理；Android 下载进度截图仅保留为品牌参考。

## 9. UI07：网络与页面错误

页面初次加载和最多三次自动重试期间静默遮住 WKWebView 系统错误内容；不显示倒计时或重连文案。最终失败显示“页面暂时无法加载”、短错误说明及 H5_DNS / H5_CONNECT / H5_TIMEOUT / H5_SSL / H5_HTTP_503 等业务错误码。

错误正文 14–16pt；主操作“重试”，次操作“应用设置”。iOS 无法通用打开 WLAN/蜂窝开关页面，不使用 App-Prefs 私有 URL。没有可打开设置入口时保留手动操作说明；不能让按钮无回调地失效。

无网络：提示“请检查 WLAN 或移动数据”。网络状态只作提示，不作为阻止实际网络请求的唯一条件。请求错误可重试；SSL 不允许“忽略证书继续访问”。

隐私拒绝页使用“需要同意隐私政策后继续”，提供“查看协议”“重新选择”；不提供调用 exit 的“退出应用”按钮。

### UI10：隐私撤回（需求已确认）

入口位于可信 H5 的“账号/隐私设置”，不是错误页的“应用设置”。原生确认框采用浅色品牌卡片，标题 17pt、正文 14pt 起，左右安全内边距至少 16pt；操作按钮至少 44pt 高，取消为次操作、确认撤回为品牌红主操作，遮罩不代替用户确认。

确认文案：“撤回后将退出当前游戏，并清理本机登录与游戏存储数据。服务端账号不会因此注销。是否继续？”操作为“取消”“确认撤回”；取消完整保留游戏状态。清理期间显示“正在清理本机数据…”，无百分比、防重复提交；完成显示“已撤回隐私同意”，提供“查看协议”“重新选择”。失败显示“部分本机数据未能清理，请重试”，提供“重试清理”，保持隐私撤回状态。新增 Bridge 与清理恢复详见总体方案 §4.1.1；再次启动不得被 privacyAuto=false 自动重新同意。

## 10. UI08：悬浮球、窗口、常亮

- 默认/激活图片地址来自初始化，Bridge 和心跳切换状态，保持原始比例；相同 URL 与状态不重复闪烁加载，GIF 使用静态首帧。
- 视觉尺寸按服务端逻辑值和 Android 已确定布局口径适配，iOS 坐标为 pt；控件限制在当前 safeArea 内。
- 仅纵向拖动，位置保留到当前会话；容器尺寸变化（含旋转）按配置重新布局，与当前 Android 源码一致。点击与拖动阈值为 8pt，超出后不触发福利。
- 游戏页面可见后创建；福利置顶时临时隐藏；游戏置顶或福利关闭恢复最新运行态。
- 运营弹窗后项在上；初始化功能实例不被清单清理。关闭任何实例，消息权限立即移除。
- 游戏成功显示后前台常亮，福利/运营覆盖时仍常亮；关闭游戏、logout、退后台恢复自动锁定；手动电源键仍生效。

H5 窗口沿用 200ms 淡入淡出。配置完全透明背景时，底层游戏仍可见；不得无意放大可穿透点击范围。

实现状态（2026-11-02）：悬浮球及心跳 `floating_ball` 已接入；`popup_pages` 运营清单、常亮和窗口动画仍属后续目标，不能将本节整体视作已验收。实现及模拟器证据见 [悬浮球对齐记录](iOS悬浮球需求与实现_ios-floating-ball.md)。

## 12. 需要确认的 UI 差异

| 差异 | Android 当前 | iOS 设计建议 | 原因 |
| --- | --- | --- | --- |
| 协议字号 | 常规 10dp、极小窗更小 | 12pt 起 | iOS SDK 小于 12 不生效 |
| 授权按钮 | 30–44dp，紧凑可低于 30 | 可见 44pt，最低 40pt | iOS SDK 与操作性 |
| 号码字号 | 紧凑可能小于 16 | 最低 20pt 设计、SDK 下限 16 | 号码可读性与 SDK 限制 |
| 小图形命中 | 随当前实现尺寸 | 至少 44pt 透明命中 | iOS 操作体验 |
| 布局视口 | 沉浸式全屏 | 背景全屏、前景避让安全区 | 刘海和 Home 指示条 |
| 更新大小 | Android 0.7 缩放与 iOS 尺寸口径不同 | iOS 直接使用 dp 或百分比 | 满足 iOS 更新弹窗配置要求 |
| 更新下载态 | 应用内 APK 下载/安装 | 仅交接 HTTPS 更新入口，本次不设计安装 UI | 本次范围与平台能力 |
| 拒绝隐私 | 可结束 Activity | 保留说明与重新选择 | iOS 不程序退出 |

确认后将这些平台差异补回共用需求，并锁定 UI 版本；iOS 初次实现不得宣称在所有极端尺寸上与 Android 像素级相同。
