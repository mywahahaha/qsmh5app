# iOS 图片与打包器实施记录

日期：2026-11-03。对应[需求分析](iOS游戏背景闪图与打包器需求分析_ios-assets-packager-feasibility.md)，按图片能力、通用构建后端、Mac 界面顺序实现；Android 代码与原打包器未修改。

## 一、已实现

### 图片与页面

- 初始化解析可选 `data.bgImage`，缺失、类型错误或不允许的地址回退为空，不阻塞初始化。
- 根容器增加全屏远程背景、前景 H5、悬浮球与启动闪图；H5 外层、WKWebView、滚动及页面下方背景透明。
- 图片使用无 Cookie/凭据/缓存的独立会话，HTTPS 或准确的本地测试来源，重定向检查；10 秒请求、15 秒总超时，16MB 下载上限，6000 万像素上限，ImageIO 按视口降采样。
- 请求代次与取消校验，旧图片不能污染新初始化；重新初始化及隐私清理撤下旧图，普通窗口切换保留背景。
- 本地闪图由 JSON 清单驱动，按同方向、对数宽高比差、同比分辨率选图；黑底 aspectFill。构建 6 调整为等待初始化联网期间保留闪图，初始化成功后最短 1.2 秒、最长 5 秒，首个 H5 就绪后结束，业务错误/SDK/必要原生交互优先撤下，详见[首次联网修复](iOS首次联网与授权闪退修复_ios-startup-auth-fix.md)。
- 静态黑色系统启动画面与应用内闪图分开；前后台、福利和退出登录不重播应用内闪图。
- 导航前准备 Bridge 文档标识及脚本。文档结束后的两次帧回调通知页面就绪，`didFinish` 兜底，执行 200ms 淡入；`didCommit` 不再直接视为已可见。帧回调不等于系统 GPU 合成完成，最低 iOS 及设备白闪效果仍需安装观察。
- H5 无需新增业务 Bridge。需要透出底图的页面应设置透明背景；不强制改写游戏全站 CSS。

默认工程包含现有 1280×768 横屏闪图和游戏 29 图标；打包器按每次配置替换。现有 512 透明圆角图标经显式兼容转换生成 iOS 资产，正式设计仍建议提供 1024 不透明无圆角原图。

### 多游戏构建与签名

- 每次配置生成桌面名称、游戏 ID、Bundle ID、版本/构建号、完整方向集合、图标、闪图清单、游戏地址与可选渠道目录。
- 默认游戏地址为空，使用初始化配置；游戏 29 样例显式保留用户指定地址。包内覆盖仍受运行时同源检查。
- 临时工程隔离、独立 DerivedData，保留已安装 SDK，排除旧产物、证书及普通本机签名覆盖文件。
- 匹配有效钥匙串私钥、证书和描述文件，检查 Bundle/团队/有效期；支持实际材料对应的 Ad Hoc、Development 或 Enterprise 设备导出，不包含商店上传。
- 最终 IPA 独立解包验签，检查实际签名叶证书、内嵌 profile、应用权限身份、调试权限、生产隔离、游戏配置、渠道目录、SDK 和闪图资源；输出哈希与摘要。
- 非敏感资源清单随包供追溯；密码、私钥和签名资料不进包。失败不发布成功包，取消停止进程组并清理，任务临时 profile 最终恢复。
- 原 `export_signed.py`、`archive_unsigned.sh` 和 `verify_archive.py` 接入通用配置，使用方式见[打包器指南](../ios/Packager/使用指南_usage.md)。

### Mac 工具

- SwiftUI 原生界面；配置加载/保存、游戏参数、图标/闪图预览、环境选择、钥匙串身份、描述文件、进度与取消。
- P12/PFX 通过 Security API 导入登录钥匙串，安全密码输入只在原生内存中使用，导入后清空；已有匹配身份无需导入。本轮未重新导入用户身份。
- 首版工具依赖本机工程、完整 Xcode 和 Python 3.11+。生成的 `.app` 使用临时签名，未公证，面向本机使用。

## 四、空渠道目录修正

用户要求空渠道码不添加空目录，检查旧构建 4 IPA 发现仅有空的 `packCode/` 根目录，没有渠道子目录。现调整为：空渠道不生成渠道目录，默认工程也排除该资源；非空渠道显式启用并在签名前生成对应子目录。最终校验新增“空渠道出现 `packCode/` 即失败”的检查。

Mac 工具内置后端已同步更新。新签名母包输出至 `ios/artifacts/交付_20261103_空渠道无目录_AdHoc/`；此前“最终”目录保留为历史产物，不代表此项修正已包含其中。

验证结果：后端 8 项测试通过；新签名母包解包确认 `packCode` 条目为 0；另行构建非空渠道 `1-218` 的未签名验证包，确认渠道目录为 `packCode/1-218/`，最终配置校验通过。
