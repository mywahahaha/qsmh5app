# iOS授权品牌UI与全屏容器修复

日期：2026-11-03。对应构建 7，版本 `1.0.1`。依据[一键登录独立需求](阿里云一键登录独立需求_aliyun-onekey-login.md)、[iOS 原生 UI 规范](iOS原生UI设计规范_ios-native-ui-design.md)、[设计预览](iOS原生界面预览_ios-native-ui-preview.html)，并核对 Android 的 `OnekeyAuthUi.kt`、`OnekeyHeaderView.kt`；本轮仅修改 iOS 与共用文档。

## 授权弹窗

旧实现仅接通 SDK 生命周期和协议，仍使用默认全屏页面、导航标题与默认控件样式。本轮将品牌 UI 接入真实 `TXCustomModel`。

| 项目 | 本轮实现 |
| --- | --- |
| 面板 | 按当前宿主窗口 safeArea 再内缩 12pt 的可用区域，分别乘服务端宽高百分比，居中；默认 60% × 75%，不暗改比例 |
| 遮罩与卡片 | 黑色 45% 遮罩、`#EEEEEE` 不透明底、14pt 圆角；遮罩点击不关闭 |
| 头部 | 43.7pt、`#C52D28` 弧形矢量路径、原始品牌 Logo、白色细线关闭；隐藏 SDK 默认 Logo 和文字标题 |
| Logo | 从 `docs/assets/onekey-login/box_logo.png` 复制到 iOS `Resources/AuthBrand`，90×30pt 等比显示，非游戏桌面图标 |
| 号码和说明 | 脱敏号码由 SDK 提供；号码 28pt / 紧凑 20pt。运营商名称取 SDK 公开 `TXCommonUtils.getCurrentCarrierName()`，未知时保留 SDK 原生说明，不固定为某家运营商 |
| 主操作 | 服务端 `login_text`、16pt 白字、`#FF6600` 背景、5pt 圆角、宽约 82%、高 44pt；其他方式 13pt、44pt 点击区 |
| 协议 | SDK 原生协议与复选框；默认未勾选，12pt 文本、蓝色链接；`expandAuthPageCheckedScope=true` 使普通说明切换勾选，链接继续只打开详情 |
| 复选框 | 14×14pt 可见图形，44×44pt 控件与透明内边距，橙色选中态 |
| 协议详情 | SDK 原生页面，品牌红导航栏、白色返回图形/标题；返回不创建新授权页，不自动勾选 |
| 方向与动画 | 保留构建 6 的实际包方向设置；约 200ms 淡入淡出，减弱动态效果时关闭非必要动画 |
| 取消与回退 | 关闭/其他方式取消当前流程；等 SDK 完成授权页关闭后再继续兑换或回退；旧回调按流程 ID 失效 |

现网曾返回宽 50%、高 70%，客户端按这两个值执行，不写死为默认比例。方向以实际游戏包允许方向为准，不能因服务端兼容字段将横屏包的授权页切回竖屏。

### 紧凑配置

按真实业务协议名称与三家运营商条款的保守换行高度测量；优先压缩非触控间距，保持按钮/其他方式 44pt、协议至少 12pt。SDK 号码控件只接受 x/y，布局额外预留号码栏原生留白。最终在 SDK 公开布局回调中检查实际号码、说明、按钮、其他方式和协议框的位置、完整高度及是否相互重叠。

无法容纳时回退 H5 登录；不偷偷增大百分比，不把协议裁掉或缩成不可读文字。`ui.title`、`ui.primary_color` 保持兼容但不覆盖固定品牌视觉。错误类型的比例、非法协议地址、重复协议名称和无法完整显示的按钮文案也走回退。

全部基于[阿里云公开 UI 配置](https://help.aliyun.com/zh/pnvs/developer-reference/the-ios-client-access)与锁定 SDK 2.14.19 的头文件；没有遍历或修改 SDK 私有视图，也没有在号码、登录或协议上叠加自制点击层。认证、协议校验、临时凭证和服务端兑换仍由原流程完成。

## H5 容器

- **宽高同时为 `100%`：** WebView 及其外层控制器铺满根视图 `bounds`，忽略偏移，不再按 safeArea 缩小。游戏和所有业务 H5 实例共用此规则。
- 其他百分比或数值尺寸仍在 safeArea 内计算，保留居中和边界限制。悬浮球继续避让刘海与手势区。
- 关闭原生根页面拖动、回弹、横竖滚动条、双指缩放、顶部回滚、前后滑动导航和链接预览；自动 content inset 与 indicator inset 为零。
- 为主文档补充 `viewport-fit=cover`，保留已有 viewport 的其他参数；隐藏网页滚动条并阻止 HTML 原生拖拽，不取消 H5 的普通触摸、按钮和输入事件。
- 根视图隐藏状态栏；Home 指示条仍由系统管理。H5 应通过 `env(safe-area-inset-*)` 保护关键操作，背景可延伸到四边。
- 不重写业务页面自行声明的 margin/padding，也不强制修改内部滚动区。长协议或长表单需由 H5 自身提供内部阅读区域；SDK 管理的协议详情保留正常阅读和返回。
