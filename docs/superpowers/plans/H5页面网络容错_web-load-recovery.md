# H5 页面网络容错实施计划

**目标：** 隐私页、登录页和游戏页加载异常时始终展示原生加载或失败面板，有限重试后提供错误码、重试和网络设置入口。

**实现：** 在共用 WebContainer 中为每个 WebView 增加独立原生容器及加载控制器。状态策略负责最多三次尝试；每次最多十秒，自动重试间隔一秒、两秒。只对主文档失败处理；证书错误取消访问，HTTP 4xx（408、429 除外）直接提示。成功以主文档可见提交回调为准，失败后的完成回调不得隐藏面板。刷新、切换地址、关闭窗口必须管理计时器及状态。

**约束：** 使用现有 Kotlin、Android WebView 和 JUnit/设备测试，不引入依赖。在当前工作目录继续尚未提交的工程，不创建缺少未跟踪工程文件的工作树，不提交代码。错误提示不展示完整 URL 或账号信息，不绕过代理或证书设置。

## 实施步骤

- [x] 先增加真实 WebView 回归测试：HTTP 503 三次失败后的原生错误面板、恢复后手动重试、404 不重试、子资源失败不挡主页面。运行并确认现有实现失败。
- [x] 增加纯状态策略及测试，覆盖代理错误分类、重试上限、超时、成功后忽略迟到错误、关闭后停止重试。
- [x] 实现原生加载面板、失败错误码、重试和网络设置；接入 WebContainer 的主文档网络/HTTP/SSL 回调以及窗口关闭、刷新、切换地址。
- [x] 设备回归覆盖挂起连接的十秒超时、恢复后成功、真实加载失败页面被遮挡、Bridge 和页面层级不回归。
- [x] 执行 Android 单元测试、设备测试、Release 构建；更新中文联调说明并审查改动。

## 验证重点

- 子资源 404 不应替换已加载页面。
- 失败后 onPageFinished/onPageCommitVisible 不应露出系统错误文档。
- 同一窗口关闭后不得继续计时或重试。
- 重试成功后显示页面并保留 Bridge；多窗口不能互相遮挡。
- 游戏内已提交页面的子资源/接口失败不触发整页刷新。

## 实施记录

- 自动重试只对可确认的 GET 导航启用。POST 等非幂等主文档失败后直接提示，手动恢复回到最近明确的 GET 页，避免丢失正文后误发 GET 或重复提交表单。
- 独立审查发现重定向目标 URL 跟踪、POST 重放和成功后迟到错误三个边界；分别补充真实 302、POST 表单和迟到回调回归后修复，最终复核无重要遗留。
- 验证命令：在 android 中执行 `./gradlew.bat connectedDebugAndroidTest testDebugUnitTest assembleRelease --console=plain`。
- 最终结果：58 项单元测试通过；20 项设备测试中 19 项通过、1 项线上 opt-in 联调默认跳过；Release 构建通过。完整日志位于 `android/build/web-recovery-final.log`。故障夜神环境未连接，本轮未执行该环境复验。
