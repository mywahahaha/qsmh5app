# 本地存储桥接开发计划

**目标：** 为所有 SDK 注入的可信 H5 页面提供 `saveLocalStorage`、`getLocalStorage`，同步需求文档和方法清单。

**实现：** 沿用 Kotlin BridgeActions 分发和统一回调；独立 SharedPreferences 私有文件保存字符串键值，所有可信窗口共享，不与登录状态关联。保存使用同步提交，持久化成功后返回 `data:true`；读取 `data` 固定为字符串，缺失为空字符串。数字去除 JSON 解码产生的无意义小数零，其他非字符串/数字值为空字符串。

**技术栈：** Kotlin、Android SharedPreferences、Gson、JUnit、Android WebView 设备测试。

**需求依据：** 本次用户请求；详细契约同步至根目录两份开发文档。

## 初版约束与审查重点

以下记录初版实现，当前参数契约以文末「键值对象与批量数组调整」及两份开发文档为准。

- 参数直接为键值对象，每个属性写入独立 key；重复 key 覆盖，未提交 key 保留。
- 字符串、数字、布尔值、对象、数组、null、空对象及空字符串 key。
- 读取 key 必须是字符串；参数错误沿用 1001，读取失败时 data 仍为空字符串。
- 各可信页面均可读写，无登录及隐私同意前置条件；退出登录和重建存储后数据保留。
- 使用独立应用私有文件；重启保留，卸载由 Android 清除；不改既有信任范围。
- 只局部修改现有工作区，不提交用户已有未提交内容。
